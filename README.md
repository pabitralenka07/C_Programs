# C and C++ Programming Repository

A structured collection of C and C++ programs, lab exercises, data structures, and algorithms.

## 📁 Repository Structure

- **`C_Lab_Programs/`**: Lab assignments and practical experiments in C.
- **`C_Practice/`**: Comprehensive practice problems covering language fundamentals to advanced concepts.
- **`C++/`**: C++ programs and object-oriented exercises.
- **`DAA_Lab/`**: Design and Analysis of Algorithms lab implementations (Dijkstra's, Kruskal's, Prim's, Knapsack, Sorting, etc.).
- **`Data-Structure_Lab./`**: Data structure implementations (Stacks, Queues, Linked Lists, Trees, Sorting, Searching).
- **`My_C/`**: Custom programs and exercises.
- **`The-Ultimate-C/`**: Chapter-by-chapter exercises, quizzes, practice sets, and projects.
- **Root Directory**: Standalone implementations of core algorithms, string manipulation, and array exercises.

## 🛠️ How to Compile and Run

To compile any `.c` program using GCC or Clang:

```bash
# Compile
gcc -o program_name program_name.c

# Run
./program_name
```

For C++ programs:

```bash
# Compile
g++ -o program_name program_name.cpp

# Run
./program_name
```
