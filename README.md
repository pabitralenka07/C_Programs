### 3. `C_Practice/` (220 Progressive DSA Problems)
A step-by-step master problem set (`program_001.c` to `program_220.c`) taking you from fundamentals to advanced algorithmic techniques:

* **001 – 040**: Fundamentals (Basic I/O, arithmetic expressions, conditional statements, basic math)
* **041 – 080**: Loops & Pattern Printing (pyramids, diamonds, inverted numbers, character grids)
* **081 – 110**: Functions & Recursion (modular code, factorial, fibonacci, GCD, Tower of Hanoi)
* **111 – 150**: Arrays, Strings & Sorting (linear search, binary search, bubble/selection/insertion/merge sort)
* **151 – 170**: Pointers & Dynamic Memory Allocation (`malloc`, `calloc`, `realloc`, pointer arithmetic)
* **171 – 220**: Data Structures & Advanced Algorithms:
  * *171 – 180*: Linked Lists (Singly, Doubly, and Circular Linked Lists)
  * *181 – 190*: Stacks (Infix to Postfix conversion, Postfix evaluation, Balanced parentheses)
  * *191 – 200*: Queues (Linear Queue, Circular Queue, Deque)
  * *201 – 206*: Trees & Binary Search Trees (Tree traversals, BST insertion & deletion)
  * *207 – 210*: Graphs (Adjacency matrix/list, Breadth-First Search, Depth-First Search)
  * *211 – 215*: Greedy Algorithms (Fractional Knapsack, Activity Selection, Job Sequencing)
  * *216 – 220*: Dynamic Programming (0/1 Knapsack, Longest Common Subsequence, Coin Change)

## 🛠️ How to Compile and Run

### For C Programs:
Using `gcc` or `clang`:

```bash
# Standard compilation
gcc -o program_name program_name.c
./program_name

# For programs utilizing math functions (<math.h>):
gcc -o program_name program_name.c -lm
./program_name
```

### For C++ Programs:
Using `g++` or `clang++`:

```bash
g++ -o program_name program_name.cpp
./program_name
```
